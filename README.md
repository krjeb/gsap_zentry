# Zentry Awwwards Website

A visually driven landing page inspired by Zentry, built with React, GSAP, and Tailwind CSS —
recreating the scroll-triggered animation, clip-path transitions, and video storytelling patterns
that earned the original site an Awwwards Site of the Month.

## Tech Stack

- **Frontend:** React, Vite, Tailwind CSS
- **Animation:** GSAP, @gsap/react, ScrollTrigger
